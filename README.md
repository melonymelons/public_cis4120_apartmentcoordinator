# nest.

A mobile-friendly apartment coordinator with a customizable pixel-art map, shared tasks, inventory, and roommate availability.

## Run locally

```sh
npm install
npm run dev
```

Open the URL printed by Vite. On your phone, use the Network URL while connected to the same Wi-Fi.

For shared accounts and syncing, follow the [Supabase setup](supabase/README.md). Without configuration, the app saves data locally in your browser.
